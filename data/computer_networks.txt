A computer network is a system of interconnected computing devices that communicate and share resources, data, and applications using established communication protocols. Modern networks form the foundational backbone of the global digital economy, enabling real-time telecommunications, internet access, and distributed computing systems.

Network architecture is commonly conceptualized through layered reference models, most notably the OSI seven-layer model and the TCP/IP protocol suite. The transmission control protocol ensures reliable, ordered, and error-checked data stream delivery between applications, while the internet protocol handles routing and logical addressing across distinct subnets.

Routing protocols direct network traffic dynamically through optimal paths across the internet. Routers inspect incoming packet header information and consult routing tables to forward packets toward their destination networks. The border gateway protocol facilitates routing decisions between independent autonomous systems that constitute the global internet routing topology.

Network security is an increasingly vital component of network administration. Modern enterprise architectures deploy multilayered defenses, including packet-filtering firewalls, intrusion detection and prevention systems, and virtual private networks. Cryptographic transport layer security protocols encrypt sensitive application traffic to prevent eavesdropping and data tampering.

Emerging networking paradigms continue to reshape connectivity paradigms. Software-defined networking decouples the network control plane from underlying forwarding hardware, allowing programmatic network configuration. Simultaneously, the rollout of high-speed fifth-generation cellular networks and fiber-optic backbones accommodates the expanding explosion of Internet of Things devices.
Wireless networking architectures employ radio frequency and microwave transmission to facilitate untethered communication across local, metropolitan, and personal area networks. The IEEE 802.11 Wi-Fi family of standards uses orthogonal frequency-division multiple access and multi-user multiple-input multiple-output antenna arrays to multiplex high-density data streams across crowded unlicensed radio spectra. Cellular telecommunication generations have evolved from early analog voice transmission to modern 5G New Radio, utilizing millimeter-wave frequencies, beamforming antenna arrays, and network slicing to deliver gigabit-per-second downlink throughput with sub-millisecond air-interface latency for mission-critical automation.

Distributed cloud computing architectures rely upon sophisticated overlay networks and software virtualization to manage inter-datacenter traffic. Software-defined wide area networking abstracts physical network links, dynamically steering traffic over multi-protocol label switching, broadband internet, and cellular connections based on real-time latency, jitter, and packet loss metrics. Modern data center fabrics adopt non-blocking leaf-spine architectures with high-radix Ethernet switches, replacing legacy spanning tree protocol trees with equal-cost multi-path routing to achieve high bisectional bandwidth and predictable east-west application traffic flows.

Domain name resolution and content delivery systems form the fundamental infrastructure enabling global web accessibility. The Domain Name System operates as a globally distributed hierarchical database that translates human-readable domain names into numerical Internet Protocol addresses through recursive resolvers, root name servers, and authoritative domain nameservers. Content delivery networks deploy geographically distributed edge reverse-proxy server caches that terminate client connections in close physical proximity to end users, offloading origin servers, reducing round-trip time latency, and absorbing distributed denial-of-service volumetric cyberattacks.

Network protocol design continually evolves to address transport inefficiency and modern internet security challenges. The QUIC transport protocol, running over User Datagram Protocol, replaces the traditional TCP-plus-TLS handshake with a zero-round-trip authenticated connection setup that eliminates head-of-line blocking during packet loss across multiplexed communication streams. Meanwhile, the ongoing transition toward Internet Protocol version 6 expands the global address space to 128-bit addresses, restoring end-to-end network connectivity and rendering legacy network address translation mechanisms obsolete.
